## 2024-06-21 - [Hash optimizations and pow to mult conversion]
**Learning:** `hash12`, `hash13`, `hash14` in `shaders/lib/common/hash.glsl` use `tan` and `atan` functions which invoke very slow Special Function Units (SFUs). Also `pow(x, -2)` is found in `shaders/lib/pbr/material.glsl` and `shaders/lib/light_color.glsl`, which is expensive and should be rewritten as `1.0 / (x * x)`. Memory indicates that rewriting hash functions to remove SFUs (like Dave Hoskins' method) and `pow` to pure math improves performance significantly on GPUs.
**Action:** Replace `pow(abs(dot(n, w)), -2)` with `1.0 / (abs_dot * abs_dot)` (or omit `abs` since squaring handles it natively: `1.0 / (dot(n,w) * dot(n,w))`) to remove SFU usage in GLSL shaders. Replace `tan` and `atan` logic in hash functions with pure ALU operations.
