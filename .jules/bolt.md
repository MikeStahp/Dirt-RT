## 2024-05-24 - Trigonometric Function Performance in Hash Functions
**Learning:** Found that `hash(float n)` in `shaders/lib/common/hash.glsl` uses `fract(cos(n) * 41415.92653);`, relying on expensive trigonometric functions (`cos`). Memory indicated that `noised` function invokes `hash(float)` eight times per call, and `fbm3D` uses it heavily. A memory also indicated: "Ensure the `hash(float)` function in `shaders/lib/common/hash.glsl` is implemented strictly as an alias to `hash11(n)` (ALU-based) and does not regress to using expensive trigonometric operations (`cos`) to avoid SFU bottlenecks for consumers like `noised`."
**Action:** Replace the trigonometric `hash(float n)` implementation in `shaders/lib/common/hash.glsl` with an alias to `hash11(float n)` to use pure ALU-based operations, reducing SFU overhead and improving performance.
