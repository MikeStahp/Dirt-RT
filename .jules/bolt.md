## 2024-05-24 - Prefer ALU-based hash functions over trigonometric ones
**Learning:** The `hash12`, `hash13`, `hash14`, and generic `hash(float)` functions were using expensive trigonometric operations (`tan`, `atan`, `cos`). This caused a significant bottleneck on the Special Function Units (SFUs), leading to performance degradation, especially since these functions are called frequently (e.g., `hash(float)` is called 8 times per `noised` invocation, and `noised` is heavily used in `fbm3D` which makes 40 hash calls per invocation).
**Action:** Replace all trigonometric-based hash functions (`tan`/`atan`/`cos`) with pure ALU-based operations (like Dave Hoskins' method) to avoid SFU overhead. Ensure generic helper hashes like `fasthash13` and `hash(float)` act as aliases to these fast, ALU-based implementations (`hash13` and `hash11`).
