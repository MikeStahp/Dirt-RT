## 2024-05-24 - Trigonometric Function Bottlenecks in Hash Functions
**Learning:** In GLSL shaders for this Vulkanite path-tracer, fundamental hash functions (like `hash12`, `hash13`, `hash14`, and `hash`) using trigonometric operations (`tan`, `atan`, `cos`) introduce severe bottlenecks. This is because these operations rely on Special Function Units (SFUs) which are limited and cause heavy instruction latency, especially when called repeatedly in loops (like in `fbm3D` which calls `hash` 40 times per invocation).
**Action:** Always prefer pure ALU-based hash functions (like Dave Hoskins' method) over trigonometric ones to avoid SFU overhead. When replacing existing functions, maintain API contracts (e.g., using wrappers or aliases) to avoid breaking un-tested downstream dependencies.
